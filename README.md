# WaveLab – Simulacija valov

Interaktivna simulacija širjenja in interference valov na dvodimenzionalni mreži z 2D in 3D vizualizacijo.

Projekt je nastal v okviru izbirnega predmeta **Matematično modeliranje**.

## Funkcionalnosti

Program omogoča:

* simulacijo širjenja in interference valov,
* ustvarjanje začetnih valov s klikom,
* dodajanje ovir,
* izbiro vrste robov: membrana ali prosti robovi,
* 2D prikaz simulacije,
* 3D vizualizacijo iste valovne površine.

## Tehnologije

Projekt je izdelan v Pythonu in uporablja:

* **PyTorch** – numerični izračun valovne enačbe,
* **PyQt6** – izdelava grafičnega uporabniškega vmesnika,
* **PyQtGraph** – 2D in 3D vizualizacija,
* **NumPy** – delo z numeričnimi podatki.
